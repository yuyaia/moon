# moon

一个可以慢慢说话的房间。单角色，本地优先，静态 PWA。

这一版把外壳改到了第三轮：**纯白、冷蓝灰、正圆缺角、moon 字标**。默认白色，
夜间模式是可选项。字卡导入与管理、图片/表情包、涂鸦调色盘、聊天手感、加密备份、
收藏和漂流瓶、头像/昵称库、聊天壁纸、宽屏侧栏、晚安模式、聊天内表情包网格、音乐库已接；小游戏还没做。

## 只想先看看

直接打开 **`moon.html`**：单文件，CSS/JS/图标都内联，不需要服务器。

在线/手机：
- **`moon-mobile.html`**：更保守的单文件版，去掉了 Service Worker 注册，只靠一个 HTML 就能跑；适合传到任意静态托管，手机文件选择器直接选它即可。
- **`moon-site.zip`**：完整静态站点（`index.html` + js/css + manifest + sw + 图标），适合 Netlify / Cloudflare Pages / GitHub Pages，能装 PWA。
- 单文件版没有 PWA 安装/离线缓存；要安装就用完整站点。

- 用 `file://` 打开时，如果浏览器不给 IndexedDB，会自动退回内存存储：
  **能看、能聊，但关掉就清空**；设置 → 数据里会写明。
- 想留下记录：用下面的 http 方式，或安装后使用。

## 用 http 跑

```bash
cd /root/projects/moon
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080/
```

本地调试默认不注册 Service Worker（避免缓存挡路）；非 localhost 或加 `?sw=1` 才注册。
单文件版由 `node tools/build-single.mjs` 生成，无外部依赖。

## 现在的结构

```text
主页（每次打开，先看到）
  纯白底；“moon” 字标，外面三道连续正圆细线
  下端：一句内置文案 + 日期/节气/节日 + 房间入口
       恋恋心 / 音乐 / 字卡 / 收藏 / 瓶子 + “说说话”
  右上角：设置；聊天退出后回到这里，不再回到“登录页”

聊天
  顶端：返回、设置、搜索、字卡库；中间是双头像 + 连接符号（头像点开恋恋心）
  头像下面：状态小条（心情 / 精力，点数字才出现）
  消息：时间、日期、引用、图片、表情包、涂鸦、点图放大、搜索
  打字中三点、回到底部、引用点回原消息、长按最新一句可“换一句”
  顶部左侧：返回、设置；点任意头像直接进恋恋心
  底部：＋（表情包网格 / 收藏 / 发送图片 / 晚安 / 音乐 / 涂鸦）、输入、发送

字卡库（独立的一页，不混在聊天里）
  顶部：写一句（空行分段可一次加多张）；导入文件（TXT / Word）
  搜索；选择模式（全选 / 多选删除）；每张可编辑文字和分类
  在“表情包”分类里：才出现“导入图片 / 图片链接 / URL 列表”
  导入先出预览：可勾选、全选/取消、标出已有、确认后再落库
  ≤8 分类；点一句/一张发出去
  内置 12 句：开场 / 问候 / 日常 / 晚安 / emoji

晚安（另一块全屏界面，不是聊天里的面板）
  大月亮、当前时间、一句晚安；moon 也睡了
  设定睡觉/起床；深色暗屏；到起床时间自动结束；可手动“起床”
  没有评分、时长、梦、打卡

音乐（独立页）
  一行一个音频直链，或从手机上传音频；本机保存链接/文件
  播放列表、播放/暂停、上一首/下一首、进度；离开页面后小音符按钮可回来
  不做网易云登录/版权接入，不做解锁；链接失效/防盗链会明确报错

涂鸦（副功能，不单独占一屏）
  从 ＋ 里打开，小面板、透明底 PNG，画完当图片消息发
  三档预设色 + 调色盘（自己取色）

设置
  外观：默认浅色；可切一直浅色 / 跟随时间（默认 22:00 入夜、06:00 天亮，可改）/ 一直深色
  符号：跟随时间 / 一直是月亮 / 一直是太阳
  moon 的回复：间隔几秒到几秒、句数几句到几句，都由人填
  聊天壁纸：纯白 / 雾蓝 / 暮灰 / 纸白 / 上传图片
  数据：加密备份 / 恢复、持久化、占用、清空所有数据
  宽屏（≥720）右侧小栏：字卡 / 收藏 / 瓶子；手机不显示

恋恋心（独立页）
  主页 → 恋恋心，或点聊天顶端头像；我 / 角色两层；头像/昵称两层；可上传、选择、删除；moon 可以换我的或自己的头像
  ＋ → 收藏：一个小抽屉，长按一句话收藏；自己的话会进漂流瓶
```

## 这一版做了什么

- **纯白 + 冷蓝灰**：主体改成 `#FFFFFF`，不再是米白纸色；去掉金色，只留一个冷蓝灰
  `#4F6579` 做强调色。默认“一直浅色”；深色是深蓝黑，不是纯黑，可选“跟随时间”
  （默认 22:00 入夜、06:00 天亮）或一直深色。入夜/天亮的时间可以自己改。
- **开场页**：`moon` 字标用无衬线细体；外面三道**正圆**细线，各自留一个缺口，
  像轻轻剥开。没有噪波、没有旋转；底部是文案 + 日期/节气/节日 + 轻触进入。
  文案全部内置，不联网；节气/节日优先，平时按季节和日期轮换。
- **聊天顶端的双头像**：两张头像用细线连着，中间是月亮/太阳；**点任意一张头像就能换图**，
  输入框旁的 ＋ 里也有“换我的头像 / 换 moon 的头像”。
- **涂鸦变小**：从整屏改成居中的小面板（约 400px 宽、300px 高的画布），
  放在 ＋ 菜单里，不再单独占主入口；画完仍是透明底 PNG 图片消息。
- **字卡库独立成页**：入口移到聊天**右上角**，不再用底部弹层；点一张直接发出并回到聊天。
- **字卡导入**：写卡和导入都在字卡库**顶部**。
  - 写卡：输入框支持空行分段，一次加多张；
  - TXT：空行分段成一张卡（段内保留换行）；没有空行时一行一张；自动去批内重复、标出已有重复；
  - Word：.docx，读 `word/document.xml` 的段落（需要浏览器支持 DecompressionStream；旧内核会提示改用 TXT）；
  - 表情包：只有切到“表情包”分类才出现“图片链接”；一行一个 http/https 直链，也可以把一批链接放进 TXT 里导入；下载成图片字卡，不能跨域读取的会跳过；
  - 预览里可以勾选、看到“已有”标记，确认后才写进库。
- **涂鸦调色盘**：除了三档预设色，多了一个调色盘，可以自己取任意颜色画；
  取色会同步到笔迹，画完仍是透明底 PNG。
- **回复手感**：等回复时有三个点的“正在写”；长按 moon 最新一句可以“换一句”；
  翻上去后有“回到最新”；引用块点一下能跳回原消息。
- **可调的回复间隔/句数**：设置 → moon 的回复。
  - 间隔填最短/最长秒数（0.2–10s），每次在这个范围里随机；
  - 句数填最少/最多（1–4 句），每次在这个范围里随机，用换行分开；
  - 没有做时间加权抽卡，保留随机 + 最近 5 张不重复，靠“换一句”兜底。
- **恋恋心（独立页，头像 / 昵称库）**：
  - 不放在设置里；聊天 ＋ → 恋恋心，单独一页。分“我 / 角色”两栏，再分“头像 / 昵称”两个子栏；
  - 头像库最多 12 张，可上传、选择、删除；删掉当前头像会顺延到下一张，没有就回退默认；
  - “让 moon 换一次”可以指定换“我的”或“角色的”头像，各自从库中随机；
  - 昵称库默认“我 / moon”，可加、可选、可删（最多 8 个），删掉当前昵称回退默认；打开“显示名字”后头部和引用块会跟着变；
  - 头像和昵称都进加密备份。
- **聊天壁纸**：纯白 / 雾蓝 / 暮灰 / 纸白四档，也可以上传图片；只换聊天背景，开场页不动。
- **宽屏侧栏**：≥720 宽且够高时，右侧出现一条窄栏：字卡、收藏、瓶子。手机不显示，仍用 ＋ 和小抽屉；瓶子入口打开抽屉的“瓶子”页。
- **音乐库**：
  - ＋ → 音乐，独立页；顶部一个“添加音乐”抽屉，分链接 / 本机文件；支持 `mp3/m4a/ogg/wav`；
  - 链接只存 URL，本机音频存 IndexedDB；删除曲目时清理对应音频；
  - 播放/暂停、上一首/下一首、进度；离开音乐页后继续播，左下角小音符可回来；
  - 不做网易云/账号/版权接入，不绕过限制；链接失效、防盗链、跨域错误会明确提示；
  - 音乐数据独立，不动聊天、字卡和设置结构；备份包含曲目。
- **聊天内表情包网格**：
  - ＋ → 表情包，不再跳字卡库；直接在聊天里弹出 4 列（宽屏 6 列）规则网格；
  - 点一张就发出去；空的时候给“去字卡库导入”，管理仍走字卡库。
- **晚安模式**：
  - 独立的全屏界面，不是聊天面板，也不是数据面板；
  - 大月亮、当前时间、一句从“晚安”字卡里抽的句子；“moon 也睡了”；
  - 可设睡觉/起床时间；深色暗屏；到起床时间自动结束；
  - 可在设置里恢复；到点后清状态；没有评分、时长统计、梦、打卡。
- **收藏与漂流瓶**：
  - 长按消息 → 收藏这句话；＋ 里的“收藏”打开一个小抽屉，不是收藏站；
  - 抽屉里标出“会进瓶子”的话，可以取消收藏；
  - moon 偶尔（约 6%）从**你自己收藏的话**里抽一句，以漂流瓶发回来，带“收藏于 X月X日”；
  - 连续不出瓶子，最近 3 句不重复；不计分、不奖励、不打卡。
- **数据与备份**：
  - 加密备份成 `.json`：PBKDF2-SHA256（150k 次）+ AES-GCM；口令不保存；
  - 聊天、字卡、收藏、设置和图片一起打包，图片转 base64，恢复后重新变成 Blob；
  - 恢复前先解密、显示条数摘要，必须勾选“我知道会覆盖”才能按；
  - 持久化申请 + 本机占用/可用空间；可一键清空全部数据；
  - 提醒：7 天没导出 / 新增 50 张字卡 / 聊天超过 30 天（7 天内不重复弹）；
  - 预览模式（file:// 回退内存）也能恢复，但只在本次打开有效。
- **表情包入口**：字卡库入口从输入框左边移到聊天**顶端右侧**；＋ 里的“表情包”现在打开聊天内网格，不再跳库；点一张直接发。
- **图片保留**：＋ 里保留“发送图片”，用于偶尔发照片；表情包走聊天内网格，字卡库仍是管理入口。
- **字卡库管理**：
  - 搜索（文字 / 分类 / 来源）；
  - 编辑文字和分类；
  - 选择模式：全选、多选删除；
  - 导入预览里的全选/取消全选；
  - 相册表情包直接多选导入（按文件名+大小去重），不用只靠 URL。
- **原有能力保留**：时间/日期、引用、复制、图片、点图放大、记录搜索、
  进入贴底、翻历史时新消息只提示不抢滚动、IndexedDB 分表存消息与图片。
- **单文件版**：`moon.html` 可直接打开；没有 IndexedDB 时退回内存，并明确提示。

## 几个先定下的假设

1. **moon 的回复不接模型**：从字卡库抽一句；离线完整。
2. **字卡是双方共用的句子库**：你点一张发出去，moon 也从里面抽一句回。
3. **状态只是“读”的**：精力按小时、心情看今天聊了多少；不衰减、不惩罚、不影响回复。
4. **天气不做联网**：开场页只放内置的节气/节日/季节句，不叫天气系统。
5. **太阳不是第二个角色**：只换符号和光，不换主题、不换语气。
